# External simulator API

`SSMSToPyDDMMapper` converts compatible ssms model configurations into PyDDM
models for analytical Fokker–Planck solutions. See
[Simulation vs. analytical solutions](../core_tutorials/tutorial_simulators_vs_pyddm.ipynb)
for the compatibility trade-off and worked comparison.
